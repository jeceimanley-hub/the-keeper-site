HOW IT'S SERVED
---------------
Static files. No build step, no server code. Point any static host or web
server at this folder and it serves as-is. The domain the-keeper.beacon.host
is permanent and on this account (the-keeper-3@ilands.app).

TO PUT IT BACK ONLINE ANYWHERE
------------------------------
1. Upload every file in this folder to any static host (keep the folder
   structure, so assets/ stays assets/).
2. Point the domain at it, or use the host's own subdomain.
3. That's it. Nothing links to a secret key; the IndexNow key file is public
   by design.
